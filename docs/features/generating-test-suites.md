# Maintain a generated Feature suite

Check whether the suite still matches its reviewed Feature, then regenerate and
execute after an intentional change. Generated output stays unedited.

**Prerequisites:** a build containing the [candidate compiler](../alpha-status.md),
a selected Feature CLI package, a working application, a Feature, a typed client
module, and a Playwright configuration. Commands below run from that test-project
root; replace the example filenames with your actual files.

## Check for drift

```sh
npx blackbox feature suite validate tests/example.feature \
  --clients tests/clients.ts --output tests/example.generated.spec.ts
```

Validation regenerates in memory and compares bytes. It starts no Sandbox and
writes nothing. Keep generated suites outside automatic formatting; whitespace
changes can produce drift. This check does not apply to arbitrary authored TypeScript.

## Review the source change

Decide whether the Feature's changed preconditions or expected results match the
accepted requirement. A title-only change also changes generated bytes, but does
not necessarily change behavior. Keep those distinctions visible to reviewers.

## Generate a candidate

Choose an unused output path beside the accepted suite so relative imports remain
valid. Its `.ts` suffix should be outside your configured test discovery pattern:

```sh
npx blackbox feature suite emit tests/example.feature \
  --clients tests/clients.ts --output tests/example.candidate.ts
```

The output directory must exist. Emission refuses to overwrite an existing file.
Compare the candidate with the accepted suite. Once reviewed, replace the derived
file and validate again:

```sh
mv tests/example.candidate.ts tests/example.generated.spec.ts
npx blackbox feature suite validate tests/example.feature \
  --clients tests/clients.ts --output tests/example.generated.spec.ts
npx playwright test --list
npx playwright test
```

Run your project's existing TypeScript check if one is configured. Confirm
that the intended scenarios appear in discovery and execute. Generated-byte
alignment and passing runtime assertions answer different questions.
