# Compile optional Gherkin Features

Blackbox's candidate Feature compiler turns supported Gherkin sentences into
native Playwright tests. Use it when your team wants to review scenarios in
Feature/Rule/Scenario form. Native TypeScript tests remain a separate authoring path.

**Candidate implementation:** the compiler and typed clients are outside this
branch. [Availability](../alpha-status.md#candidate-apis-outside-this-branch) identifies
the source revision. The product-cache application shown in the examples is not
included. For a runnable introduction, use [the native tutorial](../getting-started.md).

## What the compiler does

| Operation                | Result                                                     |
| ------------------------ | ---------------------------------------------------------- |
| `feature step list`      | Lists supported HTTP sentences.                            |
| `feature file validate`  | Checks syntax, supported steps, and named client bindings. |
| `feature suite emit`     | Writes deterministic TypeScript to a new file.             |
| `feature suite validate` | Compares generated bytes with the existing suite.          |
| Playwright execution     | Runs the emitted assertions against the configured system. |

Automatic `feature file draft` and completed-run `feature run verify` are reserved
but unavailable in that candidate. An agent can draft a Feature as a normal file
for review; it must not invent semantics for unsupported sentences.

## Why a Feature helps coding agents

A constrained vocabulary gives the agent specific diagnostics and keeps reviewed
expectations visible. Gherkin supplies structure; the compiler's actual sentence
library supplies executable meaning. Compilation cannot establish whether the
Feature covers every requirement or whether the application behaves correctly.

## Choose the right path

Compile when the HTTP vocabulary can express the actions and observations. Author
native TypeScript for other SDKs or custom observers. Registering an SDK does not
extend the compiler's language. Keep generated suites unedited.
