# Resolve available capabilities

Inspect the trusted installed executable's version and relevant help. Use
`blackbox skills list --json` to identify skill contributions from selected plugins.
Then check which skills are available to the current agent. An installable
contribution and an installed agent skill are separate facts.

Discovery owns static inspection and audit contracts. Catalog and Capsule own
their command guidance. Follow [package routing](package-routing.md) and load an
integration only when available. Do not download a package to detect support.

Keep a record of the version, supported operation, schema identity and missing
capability. Registration alone does not establish implemented runtime behavior.
Language-neutral inspection does not imply a matching activation, acquisition,
readiness or observation implementation. Verify each against the selected
package's installed contract.
