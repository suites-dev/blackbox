# Support

For setup and usage, start with the [default branch README](https://github.com/suites-dev/blackbox/blob/HEAD/README.md) and the relevant package's
README. Search [existing issues](https://github.com/suites-dev/blackbox/issues)
before opening a bug or feature request. Include a minimal reproduction, versions,
platform, expected behavior, and sanitized output.

Never attach credentials or unredacted telemetry. For suspected vulnerabilities,
use the private reporting route in [SECURITY.md](SECURITY.md). This is a pre-release
open-source project; there is no guaranteed support SLA.
