# Support

For setup and usage, start with [the documentation index](docs/README.md),
[availability](docs/alpha-status.md), and [the first system test](docs/getting-started.md).
Use documentation from the same source revision as your Blackbox packages.

Search [existing issues](https://github.com/suites-dev/blackbox/issues) before opening
a bug or feature request. Include a minimal reproduction, branch and commit,
tool versions, platform, exact command, expected behavior, and sanitized output.
For Capsule problems, include the session/activity identity and relevant retained
result or cleanup status.

Never attach credentials or unredacted telemetry. For suspected vulnerabilities,
use the private reporting route in [SECURITY.md](SECURITY.md). This is a pre-release
open-source project; there is no guaranteed support SLA.
